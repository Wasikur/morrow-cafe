# Morrow Café

Landing page for Morrow, a café in Uzan Bazar, Guwahati. Plain HTML, CSS and images, no build step.

```
index.html
css/style.css
assets/images/
robots.txt, sitemap.xml
vercel.json
```

## Deploy on Vercel

Import the repo, framework preset **Other**, leave build command and output directory empty. Before going live, replace `https://morrowhouse.in` in `index.html`, `robots.txt` and `sitemap.xml` with the real domain.
